Estructura

Bloques del diálogo

Cómo se lee: cada punto ~ es una escena. Las líneas debajo se ejecutan en orden; la sangría indica qué ocurre dentro de una opción o condición. La vista de la derecha es exactamente el archivo que exportarás.

    Sintaxis esencial

    ~ startPunto de entrada predeterminado para un diálogo.
    Trompo:Frase del personaje. Usa el nombre exacto para activar su retrato.
    - OpciónRespuesta del jugador. Usa «+ dentro» para escribir su consecuencia.
    => ENDTermina la conversación. También puede saltar a otro punto.
    if …Rama condicional, sin dos puntos. Las líneas afectadas llevan un nivel más de sangría.
    [if … /]Muestra una respuesta solo si se cumple esa condición.
    $> …Cambia una variable o llama una función. Por ejemplo: EstadoPartida.trompo_conocido = true.

    Para recordar algo entre conversaciones, declara la variable en un autoload y escribe su nombre completo, como EstadoPartida.trompo_conocido. «Texto libre» conserva sintaxis avanzada importada.
