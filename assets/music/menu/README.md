# Música de menús

Esta carpeta contiene las pistas reproducidas fuera de la partida: menú principal, selección de
personaje, nueva expedición y opciones.

Convenciones:

- Usar nombres en minúsculas con `snake_case`.
- Conservar aquí únicamente archivos que Godot deba importar.
- Guardar proyectos de audio, mezclas y originales editables en `assets/art_source/audio/`.
- Preferir `.ogg` para bucles preparados para el juego; `.mp3` también puede usarse para una
  primera versión.

Ejemplo: `tema_menu_principal.ogg`.
