# Menú colgante principal

Recursos exportados que Godot utiliza para construir el menú principal.

- `support/`: soporte o anclaje superior.
- `chains/`: tramos y eslabones de cadena.
- `logo_sign/`: tabla superior sobre la que se compone el logo de Exhume.
- `boards/`: tablas simples de las opciones; no incluyen texto ni estados visuales.

Los efectos que se aplican sobre el texto viven en
`res://assets/ui/effects/main_menu/hanging_menu/`.

Los archivos editables de Krita y el SVG original se conservan en la estructura paralela
`res://assets/art_source/ui/main_menu/hanging_menu/`.
