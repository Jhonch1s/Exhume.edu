# Fuentes editables de interfaz

Aquí se guardan los originales editables de la UI (por ejemplo, archivos de Aseprite, Krita,
SVG de trabajo o composiciones). Sus exportaciones listas para Godot deben colocarse en
`res://assets/ui/`, dentro de la categoría correspondiente.

No se deben referenciar estos archivos directamente desde las escenas del juego.
