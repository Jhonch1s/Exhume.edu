# Caballero isométrico

PNG final: `sprites/knight_isometric.png`.

Convención:

- Región por frame: `64x96`.
- Cada fila representa un estado, nivel o variante del mismo caballero.
- Cada columna representa una dirección dentro de ese estado.
- No se reordenan estados o direcciones que ya estén usados por escenas.
- Fuente: `assets/art_source/aseprite/characters/player/knight/knight_isometric.ase`.
