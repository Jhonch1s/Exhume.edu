# Máscaras de niebla para fuentes de luz

Coloca aquí los PNG de máscaras utilizados por el FOV.

Cada máscara elevada debe contener:

- La niebla correspondiente al tile base de `64x32`.
- La silueta irregular de la parte del objeto que sobresale.
- Transparencia fuera de ambas formas.

Mantén, cuando sea posible, la misma cuadrícula que el atlas visual correspondiente.
