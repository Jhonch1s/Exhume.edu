# Pisos isométricos exportados

Coloca aquí los archivos PNG que Godot debe importar.

Convención inicial:

- Región por tile: `64x32` píxeles.
- Cada fila representa una familia de piso.
- Hasta cinco columnas de variantes por familia.
- Las familias nuevas se agregan al final; no se reordenan filas existentes.
- El archivo fuente de Aseprite se guarda en `assets/art_source/aseprite/tiles/terrain/floor/`.
