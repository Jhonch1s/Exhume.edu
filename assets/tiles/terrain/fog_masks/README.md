# Niebla base del terreno

Coloca aquí las máscaras planas para celdas de altura `0`.

Archivos recomendados:

- `terrain_fog_hidden.png`
- `terrain_fog_explored.png`

Convención:

- Región: `64x32`.
- `hidden`: negro con alfa `255`.
- `explored`: negro con alfa `153` (60%).
- Ambas versiones deben compartir exactamente la misma cuadrícula.
- Fuente Aseprite: `assets/art_source/aseprite/tiles/terrain/fog_masks/`.
